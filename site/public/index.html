Link Scrub removes share trackers from links you copy or open on X, YouTube, Instagram, Threads, TikTok, Spotify, Facebook, Reddit and LinkedIn. Runs entirely offline; nothing leaves your browser.

Install it

Link Scrub isn't in the Chrome Web Store, so you load it yourself. It takes about a minute.

  1. Download and unzip

    Download the zip, then extract it. You'll get a folder called link-scrub. Keep it somewhere permanent, like Documents: the browser loads the extension from that folder.

  2. Open your extensions page

    Paste this into the address bar. Browsers don't let websites link to it directly.

    chrome://extensions

  3. Turn on Developer mode

    It's a switch in the top-right corner of the extensions page (bottom-left in Edge).

  4. Click Load unpacked

    Choose the link-scrub folder. Link Scrub appears in your extensions list. Pin it to the toolbar if you want the clipboard button handy.

Firefox and Safari aren't supported yet. To update, download the new zip, replace the folder, and click the reload arrow on Link Scrub's card.

What it does

When you copy a link
"Copy link" buttons, share sheets and Ctrl+C on any website. The tracker is gone before the link reaches your clipboard.
When you open a link
Someone sends you a tracked link. The tracker is removed before your browser requests the page, so the site never learns who shared it with you.
When you click the toolbar button
For links copied from other apps. It cleans whatever is on your clipboard right now.

Short share links like vt.tiktok.com/…, spotify.link/… and Reddit's /s/… links carry the tracker inside the link itself. Link Scrub can't clean those without contacting the site, so it leaves them alone.

Your clipboard stays yours

  • No network access, no analytics, no storage, no background process.
  • On websites it never reads your clipboard. It only rewrites a link the page is already copying.
  • It reads the clipboard only when you click its toolbar button, and forgets it when the popup closes.
  • No website or other extension can talk to it.
  • About 230 lines of plain JavaScript. Read the source on GitHub.
